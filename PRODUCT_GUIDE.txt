💰 EXPENSE TRACKER MCP – PRODUCTION GUIDE

============================================================
🚀 OVERVIEW
===========

This is an AI-powered Expense Tracker built using MCP (Model Context Protocol).

Users interact using natural language, and the system automatically executes
structured operations such as adding, updating, analyzing, and exporting expenses.

No manual API calls required.

---

## 🧠 HOW IT WORKS

User Input → AI (Claude) → MCP Tools → Database → Response

Example:
"Add ₹500 grocery expense"
→ AI calls add_expense tool automatically

• Uses @mcp.resource() for metadata
• Transport: stdio (Claude integration)
